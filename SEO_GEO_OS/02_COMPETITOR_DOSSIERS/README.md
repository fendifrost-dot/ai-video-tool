# 02 — Competitor Dossiers

One dossier per tracked competitor, per brand. Dossiers are **descriptive records**, not action lists.

## The rule this folder exists to enforce

A competitor's configuration is evidence of **that competitor's choice**, not evidence of what works.
Nothing in a dossier converts to a recommendation without passing through a module, an evidence
classification, and the decision queue.

The forbidden shortcut — "competitor does X, therefore we do X" — is exactly what dossiers make tempting,
which is why every dossier carries the warning at the top of the template.

## Competitor set discipline

The competitor set is **defined, versioned, and frozen** per brand, with the inclusion basis stated:
proximity, service overlap, or SERP/AI occupancy. Changing the set mid-series invalidates every
share-of-voice and gap trend built on it, exactly as changing a prompt panel does.

**No competitor set is currently defined for any brand** (`DQ-012`). That blocks `AUTH_01`, `GEO_05`, and
every dossier here.

## Layout

`boltz/` · `fendi_frost/` · `modest/` — one file per competitor, named `<competitor-slug>.md`.
