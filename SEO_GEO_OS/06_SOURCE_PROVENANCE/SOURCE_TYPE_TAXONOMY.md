# Source Type Taxonomy

**Status:** ACTIVE · **Last updated:** 2026-08-22

Every source recorded anywhere in this OS is classified with exactly one type. The purpose is to prevent
**false source diversity** — the illusion of broad corroboration created by many URLs that all trace to
one piece of information.

## Types

| Type | Definition | Independent? | Counts toward corroboration? |
|---|---|---|---|
| `business-owned` | The brand's own website or property | No | **No** |
| `first-party-profile` | A profile the brand controls (GBP, streaming, social, storefront) | No | **No** |
| `independent-editorial` | Original reporting or review by an independent publisher | Yes | **Yes** — the highest-value type |
| `directory` | Structured listing, usually self-submitted | No | No |
| `database` | Structured record from an authoritative registry (rights, credit, business registry) | Partly | Case by case — record the reasoning |
| `syndication` | Formal republication of another source's content | No | **No** — same origin as the source |
| `derivative` | Restates another source without independent reporting | No | **No** — same origin as the source |
| `ugc` | User-generated: forums, community posts, wikis | Sometimes | Case by case — often derivative in substance |
| `social` | Social platform post | Rarely | Only if independently authored and substantive |
| `review` | Customer review on any platform | Yes, individually | Yes for experience claims; no for business facts |
| `marketplace` | Retailer or marketplace listing | No | No |
| `search-result` | A SERP or answer surface, recorded as an observation | n/a | No — it is a measurement, not a source |
| `ai-synthesis` | Text generated by an AI system | **No** | **Never** — see below |

## Core rule — information origins

**Five sites republishing one press release is ONE informational origin, not five.**

Every source row carries an `information_origin_id`. Sources sharing an origin collapse to one for any
corroboration, authority, or diversity count. Report both numbers, and lead with origins:

> "14 sources across 6 distinct information origins, of which 3 are independent."

A raw source count presented without the collapsed origin count is a misleading number and must not
appear in any report produced by this OS.

## Determining origin

1. Cluster sources by substance — near-identical wording, identical facts in identical order, or shared
   distinctive phrasing.
2. The earliest-published member of a cluster is the origin; the rest are derivatives.
3. If ancestry cannot be established, classify `unknown ancestry` and **do not count it as independent.**
   Uncertainty resolves toward the conservative answer.

Full procedure: `../03_PROMPT_MODULES/authority/AUTH_02_Source_Ancestry_Audit.md`.

## AI synthesis is never corroboration

Text produced by an AI system is **never** evidence for a fact about a brand. If an AI answer states
something not found in any retrieved source, that is a finding about the model (`GEO_04`), not a source.
Never enter an AI-generated claim into the ledger as a source supporting a fact — that is circular
sourcing, and it is how a hallucination becomes a permanent "fact" in a research system.
