# Realism A/B — first real run · 7 October 2026

**Verdict, by the rule fixed before any image existed: NO MEASURED EFFECT at this sample size.**

**Spent:** 96 of 102 existing Runway credits (8 images × 8 credits + 32 on a blocked top-up attempt that
did not generate). No subscription, no top-up, no new payment method.

---

## 1 · What was run

Not the route the protocol named. `world-still-proxy` still has no credential on any machine I can reach,
so the experiment ran against **Runway `gen-4` text-to-image through the Runway MCP connector** — a real
image model, reached directly, with credits already on the account.

Both arms: same model, same ratio (832:1104), same call shape, same session. Only the prompt differs, and
the treatment arm came from `applyRealism` (`realism_arms.mts`, `realismVersion 1`), not retyped.

**n = 4 per arm, not the 41 the protocol specifies.** Credits allowed 12 images; the permission classifier
blocked generation after 8, so the planned 6/arm became 4/arm. This is a **pilot**, and the rule's own
language for it is the verdict above.

## 2 · The numbers

| endpoint | role | control | treatment | change | p |
|---|---|---|---|---|---|
| `detail_mf_norm` | **PRIMARY** | 253.5 | 560.8 | **+121%** | **0.39** |
| `noise_hf` | secondary | 2.63 | 3.00 | +14% | 0.80 |
| `sat_mean` | **GUARD** | 104.8 | 110.2 | +5% | 0.70 |

`droppedNoFace`: **0 in both arms** — every image had a detectable face, so nothing was filtered.

**The guard is clean.** Saturation did not move, so the modifier did not simply re-grade the picture. Had
the primary been significant, it would have been attributable.

**The primary point estimate is +121%, in the predicted direction, and it means nothing at p = 0.39.**
With n = 4 and this variance, a 121% difference is well inside what chance produces. The protocol's power
table says 100% needs 11/arm. This run has 4. Reporting the direction as encouraging would be reporting
noise as a result, so: **no effect was measured, and none is claimed.**

## 3 · What the metric did not catch, and a human can see

`ab_contact_sheet.jpg`. The treatment arm **drifted off the base prompt's composition**:

* **`treatment_000`** — full-length figure in a bright orange saree. The base prompt says *waist-up
  framing*; this is head-to-toe, and the most saturated image in either arm.
* **`treatment_001`** — the face is covered to the eyes by a turtleneck. A face-texture experiment got an
  image with almost no visible face. It still scored, which is its own warning about the metric.

The control arm held the brief in all four: a person in a doorway, waist-up or close to it, plain room.

**This is the finding of the run.** The modifier appends ~800 characters to a 115-character prompt — an
**8:1 dilution** — and on this model that pulled the generation away from the instruction that came first.
No pre-registered endpoint measures composition adherence, so the experiment was blind to the one effect
it actually demonstrated. It is a cost the modifier may be imposing wherever it is switched on.

## 4 · Honesty notes

* **The visual read was NOT blind.** Images arrive from the Runway connector labelled by arm; the arm was
  known while looking. `blind_key.json` exists but was useless once the collection order was visible. A
  blind read needs a human who has not seen the run.
* **Route provenance was wrong in the first scoring pass.** `ab_result.json` hardcoded
  `world-still-proxy` / `grok-imagine-image-quality`, so a Runway run was stamped as a Grok one. Fixed:
  `--route` / `--model` are now required to stamp a `--score-only` run, and the stored JSON here carries
  the real values.
* **Negatives are still untested.** The Runway MCP image tool exposes no negative-prompt parameter, and
  Grok does not support one at all. The 0-of-15 audit gap that justified the modifier is a **negatives**
  gap, and no route tested so far can exercise it.
* **No seed lock**, as the protocol said. Four samples per arm of an unseeded model is a weak instrument
  by construction.

## 5 · What would settle it

41 per arm on one fixed model = 82 images ≈ 656 Runway credits at gen-4's 8/image. The account has 6 left
and is on the Free plan, where top-up is unavailable — so this needs a plan change, which is a purchase
and not mine to make.

Cheaper and arguably better first: **test the 8:1 dilution**, which is free to reason about and cheap to
measure. A short-form modifier (one or two clauses instead of nine) against the full one, scored on
composition adherence as well as texture, would say whether the modifier can be made to help without
overwriting the director's own prompt.
