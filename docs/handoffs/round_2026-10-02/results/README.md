Results of the paid round come back here (the repo is the bus between the agent sessions — neither can read the other's
disk, and the Cowork session cannot read storage):

* `<id>.mp4` — each Seedance angle exactly as the runner downloaded it
* `manifest.json` — the runner's manifest (jobs, costs, fidelity when the models were reachable)
* `stoop_empty.png` + `stoop_empty.json` — the empty-stoop plate and its envelope

The Cowork session then runs the $0 half on them: reference_fidelity.py, the tier-1 gate, the occluder composite on the
stoop plate, and bar5 with the angles cut in.
